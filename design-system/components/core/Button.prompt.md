Gradient primary button (cyan→blue) plus hairline ghost and danger variants — the product's main action control.

```jsx
<Button variant="primary">New invoice</Button>
<Button variant="ghost">Refresh</Button>
<Button variant="danger" size="sm">Delete</Button>
```

Variants: `primary` (gradient fill + cyan glow), `ghost` (transparent, hairline border — used for secondary/toolbar actions), `danger` (red text). Sizes: `sm` / `md` / `lg`. Add `block` for full-width (used in the login form). Pass `disabled` to dim to 55%.
