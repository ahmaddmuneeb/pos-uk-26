The POS UK logo: a cyan→blue gradient rounded square with a cyan glow, optionally locked up with the "POS / ERP — Operations" wordmark.

```jsx
<BrandMark size={36} />
<BrandMark size={48} showWordmark />
```

Used at 36px in the sidebar, 48px on the login panel. The mark scales (radius and glyph track `size`). For a standalone asset, `assets/logo-mark.svg` holds the same mark.
