Sidebar building blocks: `NavSection` (uppercase grey overline) and `NavItem` (link, muted → cyan-accented when active).

```jsx
<NavSection>Sales</NavSection>
<NavItem active>Sale invoices</NavItem>
<NavItem>Sale returns</NavItem>
```

The active item gets a cyan tint + inset accent ring. Compose inside the 252px `.sidebar` column.
