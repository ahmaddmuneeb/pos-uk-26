Pill status badge with a leading status dot. Tones map to the product's semantic palette.

```jsx
<Badge tone="success">Paid</Badge>
<Badge tone="warning">Partial</Badge>
<Badge tone="danger">Overdue</Badge>
<Badge tone="info">Draft</Badge>
<Badge tone="neutral">Inactive</Badge>
```

Set `subtle={false}` for an outline style. Good for payment status, sale-person status, document state.
